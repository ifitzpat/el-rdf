** Quelpa

The package =el-rdf= is not currently available from [[https://melpa.org/#/org-ql][MELPA]], but can be installed
directly from github with [[https://framagit.org/steckerhalter/quelpa][Quelpa]].

Installing with [[https://framagit.org/steckerhalter/quelpa][Quelpa]] is easy:

1.  Install [[https://framagit.org/steckerhalter/quelpa-use-package#installation][quelpa-use-package]] (which can be installed directly from MELPA).
2.  Add this form to your init file:

#+BEGIN_SRC elisp
(use-package el-rdf
  :quelpa (el-rdf :fetcher codeberg :repo "ifitzpat/el-rdf")
  )
#+END_SRC
